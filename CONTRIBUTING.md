# Contributing to Fix-it

Fix-it is currently a concept and specification project. Useful contributions make the vision testable.

## Useful proposals

- A concrete user journey with a starting problem and observable outcome.
- Provider qualification, inspection and dispute-handling requirements.
- A payment or ledger design with failure cases and cost assumptions.
- A reproducible test using synthetic data.
- A bounded local pilot proposal without personal customer information.

## Proposal format

Include:
1. Problem and intended users.
2. Proposed change.
3. Assumptions, dependencies and what is still unknown.
4. How success can be tested.
5. Relevant sources or evidence.
6. Privacy and operational considerations where applicable.

Use issues for non-sensitive proposals and pull requests for documentation improvements. Check repository settings for the currently enabled features.

## Public information only

Do not submit credentials, private keys, wallet recovery phrases, identity documents, personal customer records, payment details or confidential agreements.

This repository does not accept donations, sell tokens, register insured members or dispatch emergency assistance. Do not send funds to addresses posted in issues or comments.

If a security-sensitive issue arises, do not describe it publicly. Use GitHub private vulnerability reporting only if it is enabled; otherwise request a private reporting route without disclosing the issue itself.

## Review

Keep changes focused, distinguish plans from implemented behavior and avoid unsupported claims about coverage, partnerships, guaranteed returns or completed audits.

Documentation is not evidence that the proposed system has been built. Future implementation and licensing decisions will be recorded explicitly.
